      Why macOS warns about it
      
Apple lets an app skip this step if its developer pays for a yearly certificate and sends each version in to be scanned. Seyes doesn't have one yet. The warning means Apple hasn't checked the app, not that anything is wrong with it. All of its code is on GitHub.
